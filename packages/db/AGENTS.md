# Database package

## Overview

The Drizzle schema and client for PostgreSQL. It exports a `createDb` factory, and `apps/server` calls it with `DATABASE_URL`.

## Key files

| File | Owns |
|---|---|
| `src/index.ts` | `createDb` and the `Database` type |
| `src/schema/index.ts` | Exports every table, and is the schema entry for Drizzle Kit |
| `src/schema/auth.ts` | Better Auth tables, generated by `bun run auth:generate` |
| `src/relations.ts` | Combines the relations passed to the client |
| `drizzle.config.ts` | Drizzle Kit config, migrations go to `src/migrations` |
| `docker-compose.yml` | Local PostgreSQL 17 with PostGIS on port 5434, and Mailpit (SMTP on 1026, web UI on 8026) |

## Commands

Run these from the root.

```bash
bun run db:start     # start local PostgreSQL and Mailpit in Docker
bun run db:stop      # stop them, keep the data
bun run db:down      # remove the containers, keep the data volume
bun run db:push      # apply the schema directly
bun run db:generate  # write a migration from schema changes
bun run db:migrate   # run pending migrations
bun run db:studio    # open Drizzle Studio
```

## Conventions

- Put new tables in `src/schema/` and export them from `src/schema/index.ts`.
- Do not edit `src/schema/auth.ts` by hand. The next `auth:generate` overwrites it.
- Change the schema through a migration (`db:generate`, then `db:migrate`), not `db:push` (spec 0001). The migrations also enable PostGIS and add the first settings.

## Gotchas

- `drizzle-orm` and `drizzle-kit` are on `1.0.0-rc.5` and use the newer `defineRelations` API. Older examples for the `relations()` helper do not apply.
- `DATABASE_URL` is set in `apps/server/.env`, because `.env.schema` here imports it from `apps/server`.
- `drizzle.config.ts` is the one file that reads `process.env`, after loading `varlock/auto-load`.
- The password in `docker-compose.yml` is for local use only.
- `user.phone` is nullable since spec 0005 (Google accounts start without one), and stays unique. Every read of the phone has to handle `null`.
